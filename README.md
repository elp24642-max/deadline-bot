# Deadline Bot

Telegram-бот, который хранит дедлайны (лабораторные, сдачи, экзамены) и сам напоминает: за сутки и за час.

## Команды

| Команда | Что делает |
|---------|------------|
| `/add 25.11 18:00 Лабораторная по C` | добавить дедлайн (время можно не указывать, тогда 23:59) |
| `/list` | показать несданное с остатком времени |
| `/done 3` | отметить сданным (номер из `/list`) |
| `/del 3` | удалить |

## Запуск

Нужен Python 3.10+ и токен бота от [@BotFather](https://t.me/BotFather).

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
```

Создай файл `.env` рядом с `bot.py` с одной строкой (токен не публикуй, файл в `.gitignore`):

```
BOT_TOKEN=токен_от_BotFather
```

Запуск:

```bash
python bot.py
```

## Как устроено

- `bot.py`: команды бота (aiogram 3) и фоновая проверка напоминаний раз в минуту.
- `db.py`: хранение в SQLite (`deadlines.db`, создаётся сам).
- `parse.py`: разбор даты и времени из команды `/add`, форматирование остатка времени.
- `test_parse.py`: тесты разбора. Запуск: `python -m unittest`.

Часовой пояс по умолчанию UTC+4 (Ульяновск). Меняется в `parse.py`, константа `TZ`.

## Ограничения

Бот работает, пока запущен `bot.py`. Если компьютер выключен, напоминания не придут. Для постоянной работы нужен сервер или хостинг.
